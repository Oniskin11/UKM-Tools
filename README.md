# UKM-Tools

Инструмент с графическим интерфейсом и CLI для обслуживания касс UKM по SSH/SFTP.

## Что умеет

- восстановить БД кассы из дампа;
- пересобрать чистую MySQL из штатных архивов UKM, сохранив прежний каталог данных;
- установить или обновить ТС ПИоТ, драйвер ККТ и сертификат «Честного знака»;
- синхронизировать время ККТ;
- опубликовать дистрибутивы из ZIP-архива или папки на веб-сервер либо в локальный каталог.

Можно работать с одной кассой или со списком адресов. В GUI видны шаги операции, их статус и журнал выполнения.

## Быстрый старт

Требуется Python 3.11+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install .
Copy-Item config.example.toml config.toml
python -m dbrepair.cli --gui --config .\config.toml
```

Заполните в `config.toml` как минимум секцию `[connection]`. Для восстановления БД также нужны `[database]` и `[paths]`; для установки ТС ПИоТ — `[distribution]`.

### Запуск без Python

Скачайте [DbRepair.exe](release/DbRepair.exe) и положите рядом `config.toml` (его можно создать из `config.example.toml`). Программа запускается двойным щелчком и не требует установки Python.

## Запуск

```powershell
# Графический интерфейс
dbrepair-gui --config .\config.toml

# Восстановление БД
dbrepair --config .\config.toml

# Установка ТС ПИоТ на указанные кассы
dbrepair --tspiot --hosts 192.168.51.101,192.168.51.102 --config .\config.toml
```

## Дистрибутивы ТС ПИоТ

В качестве источника укажите HTTP-адрес (`[distribution].base_url`) или локальный каталог (`[distribution].local_dir`). В разделе «Публикация файлов» выберите архив или папку от разработчика: программа сама найдёт драйверы ККТ, `tspiot*` и `gismt_cert.txt`, определит архитектуру и разложит файлы в единую структуру.

```
UKM/
├── kkt/<версия>/<x64|x86>/libsp-kkt-driver-*.so
├── tspiot/<версия>/<x64|x86>/tspiot
└── gismt_cert.txt
```

Рядом с файлами создаются контрольные суммы `.sha256`, а `latest.json` указывает актуальную версию. При установке касса получает только изменившиеся файлы.

## Конфигурация и безопасность

Полный перечень настроек приведён в [config.example.toml](config.example.toml). Пароль веб-сервера можно хранить в `.env` рядом с конфигурацией как `UKM_PUBLISH_PASSWORD`; этот файл исключён из Git.

Операции с MySQL изменяют данные кассы. Перед восстановлением или пересборкой убедитесь, что указали правильный адрес и сохранили нужные резервные копии.

## Разработка

Тесты нужны и хранятся в репозитории: они проверяют сценарии публикации, выбора актуальной версии и обслуживания касс.

```powershell
pip install pytest
pytest -q
```
